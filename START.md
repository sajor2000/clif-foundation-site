# Start here

## Local

```bash
npm install
npm run dev   # → http://127.0.0.1:43127
```

No environment variables are required. Full notes: `README.md`.

## Vercel (production)

1. Import https://github.com/sajor2000/clif-foundation-site in Vercel (build settings live in `vercel.ts`).
2. Push to `main`.
