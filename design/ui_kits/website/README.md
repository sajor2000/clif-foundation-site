# CLIF Foundation website — UI kit

Click-through of the proposed website composed only from design-system components. Home, Research & Resources, and Support are interactive; Mission, Our Work, and Board navigate home in this kit. The full six-page prototype lives in `CLIF Foundation Site.dc.html` at the project root.

Screens: Home (hero + organization.record, programs table, publications) · Research (filter chips, publication rows) · Support (inquiry-only giving, audience pathways).
