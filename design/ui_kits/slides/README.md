# CLIF Foundation — slide template

1920×1080 deck built on `deck-stage.js`, `../../styles.css`, and `slides.css`. Ten layouts; copy the sections you need.

| Layout | Ground | Use |
|---|---|---|
| Title | ink | Opening; white lockup, display headline, one status tag |
| Agenda | page | ≤ 6 numbered items |
| Section | ink | Between major parts; mint 220px index |
| Statement | page | One claim (≤ 12 words) + support + source |
| Compare | page | Existing (white head) vs proposed (mint head) |
| Data table | page | Mono header band, snake_case ids, status tags |
| Process | page | 3–5 steps; last step mint |
| Discussion | page | Context list + ink "for discussion" panel |
| Figure | page | One DataPanel, labeled illustrative |
| Close | ink | One ask; contact in signal |

Rules: text ≥ 24px; max two grounds (page, ink); one accent family (petrol for text and links on light, mint as fill or on ink); footer on every page-ground slide; speaker notes in `data-speaker-notes`. The board meeting deck at the project root follows this template.
