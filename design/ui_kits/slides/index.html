01 — How CLIF research works

Data stays at each hospital. Code travels.

Each site converts its EHR data to CLIF locally, runs shared analysis code, and returns only aggregate results.

Source: CLIF Consortium, clif-icu.com04
02 — Relationship

Two organizations, distinct roles

Consortiumexisting
Conducts federated, multicenter research
Maintains the standard and data dictionary
Publishes tools and studies
Patient data stays at each site
Foundationproposed
Supports adoption at more institutions
Education and implementation support
Sustains open-source maintenance
Does not conduct research or hold patient data
