Square-cornered action button; ink primary for the main action, outline secondary beside it.

```jsx
<Button href="/support">Support CLIF</Button>
<Button variant="secondary" href="/mission">Read the mission</Button>
```

- Hover on primary shifts ink → signal-700; never fill a button with signal-400 on light grounds.
- Use `size="lg"` + `fullWidth` for stacked mobile CTAs.
- `inverse` is for ink sections and the footer.
