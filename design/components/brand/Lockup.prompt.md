The CLIF Foundation lockup: original CLIF logo in one color, a 1px rule, and "Foundation" in Funnel Display.

```jsx
<Lockup />                      // header on light
<Lockup tone="inverse" />       // footer / ink sections
```

- Ink tone is a CSS filter on the original PNG until an official one-color file is supplied.
- Never recolor the logo petrol or mint. Crimson (`tone="consortium"`) is reserved for Consortium credit.
